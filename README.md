CargoBot Kids Web

Projeto simples para ensinar lógica de programação com uma garra estilo CargoBot.

Como rodar:
1. Abra um terminal nesta pasta.
2. Execute: python server.py
3. Abra no navegador: http://127.0.0.1:8000

Comandos aceitos no editor:
- direita
- esquerda
- descer
- esperar 400
- repita N { ... }

Observações:
- Descer funciona como pegar/soltar caixa (toggle).
- O simulador mostra a posição da garra e as pilhas em tempo real.

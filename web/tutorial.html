🎯 O que é CargoBot Kids?

CargoBot Kids é um playground de programação onde você controla uma garra robótica usando comandos em português.

A garra pode:

  • 🔴 Mover para a direita
  • 🔵 Mover para a esquerda
  • 🟢 Descer para pegar ou soltar caixas
  • 🟡 Esperar um tempo antes do próximo comando
  • ⭐ Repetir um grupo de comandos várias vezes
💡 Dica:

Pense nos comandos como instruções que você dá ao robô. Ele vai executar exatamente o que você escrever!

🎮 Comandos Disponíveis

Existem 7 comandos principais que você pode usar:

direita

Move a garra um espaço para a direita

direita

esquerda

Move a garra um espaço para a esquerda

esquerda

descer

Desce a garra para pegar ou soltar uma caixa

descer

esperar N

Aguarda N milissegundos (1000 = 1 segundo)

esperar 500

repita N { ... }

Repete os comandos dentro das chaves N vezes

repita 3 { direita }

func nome { ... }

Declara uma funcao com um nome para reutilizar comandos

func moverDireita { direita }

chamar nome / nome()

Executa uma funcao que você declarou

chamar moverDireita

📝 Regras Importantes

  • Os comandos devem estar em português
  • Um comando por linha é mais fácil de ler
  • Você pode usar # para adicionar comentários (notas para você)
  • A garra tem 7 pilhas (P1 a P7) onde as caixas são armazenadas
✅ Exemplo correto:
# Mover para direita func passoDireita { direita } chamar passoDireita passoDireita() descer

📖 Exemplos Práticos

Exemplo 1: Mover a Garra

Vamos começar simples - apenas mover a garra para a direita:

direita direita direita

O que acontece: A garra se move 3 vezes para a direita. ↪️➡️➡️

Exemplo 2: Pegar uma Caixa

Agora vamos pegar uma caixa da pilha inicial:

direita descer

O que acontece: A garra se move 1 vez para a direita, depois desce e pega a caixa do topo da pilha P2.

💡 Dica:

Quando a garra desce em uma pilha com caixas, ela pega a caixa do topo. Quando desce já segurando uma caixa, ela solta a caixa.

Exemplo 3: Mover Caixa para Outra Pilha

Vamos pegar uma caixa e levar para outra pilha:

# Pegar a caixa de P1 descer # Mover para a pilha P2 direita # Soltar a caixa descer

O que acontece: A garra pega a caixa de P1, se move 1 espaço para a direita (P2) e solta a caixa lá.

🎯 Exercício 1:

Tente pegar a primeira caixa (amarela) e mover para a pilha P3. Escreva os comandos no playground!

Exemplo 4: Funcoes

Funcoes ajudam a reutilizar passos sem repetir tudo:

func pegar { descer } func soltar { descer } chamar pegar direita chamar soltar

🔄 Usando Repetição

Às vezes você precisa fazer o mesmo comando várias vezes. Em vez de escrever direita 5 vezes, use repita!

Sintaxe da Repetição

repita N { comando1 comando2 ... }

N é o número de vezes que você quer repetir. Os comandos dentro das {chaves} serão repetidos N vezes.

Exemplo: Ir Muito Longe

Sem repetição (trabalhoso):

direita direita direita direita direita direita direita

Com repetição (muito melhor!):

repita 7 { direita }

Resultado é o mesmo, mas o código é muito mais limpo! 🎉

Repetição Aninhada (Avançado)

Você pode colocar uma repetição dentro de outra:

repita 3 { descer repita 2 { direita } }

Este código:

  1. Desce a garra
  2. Move 2 vezes para a direita
  3. Repete tudo isso 3 vezes
🎯 Exercício 2:

Use repita para mover a garra para a direita 5 vezes em uma só linha de código!

🐛 Resolvendo Problemas

❌ Erro: "A garra saiu da área"

O que significa: A garra moveu-se demais para a direita ou esquerda, saindo do campo de jogo.

Solução: Conte as pilhas (P1 a P7) e não mova além da pilha 7 para a direita ou antes da pilha 1 para a esquerda.

❌ Erro: "Comando desconhecido"

O que significa: Você escreveu um comando que o robô não conhece.

Comandos válidos são: direita, esquerda, descer, esperar, repita

Verificar: Certifique-se de estar escrevendo em português e sem erros de digitação.

❌ Erro: "Sintaxe inválida"

O que significa: Há algo errado com a estrutura do seu código.

Causas comuns:

  • Esqueceu as {chaves} no repita
  • Esqueceu o número depois de esperar ou repita
  • Chaves desbalanceadas (mais de um tipo que do outro)
❌ Errado:
repita 5 direita

Problema: Faltam as chaves {}

✅ Correto:
repita 5 { direita }
💡 Dica de Debug:

Se receber um erro, leia a mensagem com atenção! Ela mostra qual é o problema. Use os botões Direita, Esquerda, Descer para testar a garra manualmente.

⭐ Desafios para Praticar

Desafio 1: Mover Todas as Caixas

No playground, há 4 caixas na pilha P1 (amarela, azul, verde, vermelho). Seu desafio:

  • Mover todas as 4 caixas para a pilha P2
  • Depois mover todas as 4 para a pilha P3
  • Depois mover todas as 4 para a pilha P4

Dica: Use repetição! 🔄

Desafio 2: Organizar as Caixas

Coloque as caixas em uma ordem específica:

  • P1: Amarelo
  • P2: Azul
  • P3: Verde
  • P4: Vermelho

Desafio 3: Criar um Padrão

Use repetição aninhada para criar um padrão. Por exemplo:

  • Pegue uma caixa
  • Mova 2 espaços para a direita
  • Solte a caixa
  • Repita 3 vezes
💡 Solução do Desafio 1:
# Mover 4 caixas de P1 para P2 repita 4 { descer direita descer esquerda }
